## 🧑‍💻 Sobre mim

Tenho 21 anos e sou estudante de **Engenharia de Software** na UMC (Universidade de Mogi das Cruzes), com formatura prevista para **2027**. Meu foco está no desenvolvimento **backend**, **Inteligência Artificial aplicada** e **segurança da informação**.

Acredito que a melhor forma de aprender é construindo projetos reais — por isso cada semestre inclui pelo menos um projeto prático que vai para o portfólio. Atualmente estou desenvolvendo meu **TCC**: um chatbot baseado em **RAG (Retrieval-Augmented Generation)** para responder dúvidas dos alunos da UMC sobre o regulamento acadêmico.

- 🎓 7º semestre em Engenharia de Software — UMC, Mogi das Cruzes/SP
- 🤖 Desenvolvendo TCC: chatbot RAG com Node.js, TypeScript e pgvector
- 🔍 Buscando **estágio em desenvolvimento de software ou IA** na região de Mogi das Cruzes/SP
- 📚 Estudando: LLMs, embeddings, arquitetura de sistemas distribuídos

## 🚀 Projetos em Destaque

### 🤖 [tcc-chatbot-umc](https://github.com/FernandoTakagi-code/tcc-chatbot-umc)
> Chatbot baseado em RAG para responder perguntas sobre o regulamento acadêmico da UMC

- Extração e chunking de PDFs com `pdfjs-dist`
- Geração de embeddings com `nomic-embed-text` via Ollama
- Busca semântica com `pgvector` no PostgreSQL 17
- Backend em **Node.js + TypeScript + Express**
- Avaliação com **RAGAS**

`TypeScript` `Node.js` `pgvector` `Ollama` `RAG` `PostgreSQL`
